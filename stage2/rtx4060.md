# GPU track — instructor notes (RTX 4060, 8 GB)

The official training pipeline is [`microduck_rl`](https://github.com/pollen-robotics/microduck_rl):
mjlab (MuJoCo Warp) + PPO, **CUDA required**. This is the pipeline that produced the
9 shipped ONNX policies our labs replay. Students never need it (Labs 6–7 train on
CPU with our SB3 track); it exists for the instructor and advanced students, and as
the conceptual bridge to the Isaac Sim half-semester (same massively-parallel model).

## Setup

```bash
git clone https://github.com/pollen-robotics/microduck_rl
cd microduck_rl
uv sync            # needs a CUDA-capable torch/warp; check their README for pinning
```

## Training

Upstream default is 4096 parallel envs, sized for bigger cards. On 8 GB start at
1024 and raise until VRAM is tight:

```bash
uv run train Mjlab-Velocity-Flat-MicroDuck --env.scene.num-envs 1024
# monitor VRAM:  nvidia-smi -l 2
```

- Upstream quotes 1–2 h to a usable gait at 4096 envs; expect roughly 2–4× that
  wall-clock at 1024–2048 envs. Overnight runs are the comfortable default.
- `uv run play` to visualize a checkpoint; resume with `--agent.load-checkpoint`.
- Export with `scripts/export.py` → ONNX with the same 61-obs contract; verify it
  in OUR sim: `OnnxPolicy(path)` + `PolicyRunner` (Lab 5 machinery), or
  `uv run scripts/play_policy.py --behavior <path>`.

## No local GPU? (students who want the advanced track)

1. **Google Colab** (free T4): `stage2/colab_train.ipynb` — our SB3 track runs
   anywhere; the microduck_rl section needs the GPU runtime.
2. **Hugging Face Jobs**: microduck_rl supports submitting training as HF Jobs
   (paid, per-minute billing) — see their README.
